# proprietary/

Intentionally empty in Atomic Borders.

Upstream OpenFront keeps its all-rights-reserved assets (logo, font, key art,
music) here. They are not licensed for use outside OpenFront, so this fork
removed them and ships its own replacements in `resources/` instead.

The build still looks in this folder (assets here override `resources/`), so
do not add files here unless you own them.
